# Datadog

This is my personal repo of useful tools I have created for datadog. Enjoy!

## Projects

- **agent_custom_check/** - Custom Datadog Agent check that counts days until Christmas
- **c-sharp-app/** - Simple C# application with Datadog integration and Kubernetes deployment
- **dotnet-app/** - .NET web application with Datadog APM, logging, and complete Kubernetes setup
- **fargate/** - Python applications running on AWS Fargate with Datadog monitoring via CloudWatch and Firelens
- **minikube/** - Datadog Agent deployment on Minikube with sample nginx application
- **n8n/** - n8n workflow automation platform with Docker Compose setup
- **spark-exercise/** - Apache Spark examples with Datadog monitoring including batch and streaming jobs
- **statd/** - StatsD examples and utilities for sending custom metrics to Datadog
- **workflows/** - Datadog Workflow automation examples and templates
